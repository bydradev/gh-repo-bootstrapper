# AGENTS.md rule map (v0.5.5 → hub and skills)

One-time audit artifact for the AGENTS.md hub restructure. Each row is one
sentence (or one command block or placeholder) of the v0.5.5 generated
`AGENTS.md` sections and the type fragments composed into them, read with
`git show v0.5.5:templates/<file>`. The new location names the file and
heading that now carries it. "hub" is `templates/AGENTS.md`; skills render to
`.agents/skills/<name>/SKILL.md`. Rows were matched mechanically
(whitespace, emphasis and link targets normalized; the first and last 60
characters must both appear) and the remainder mapped by hand with a note.
Where a sentence appears in more than one place, every location is listed.

`templates/AGENTS-nextjs-block.md` is managed by `next dev` and is rendered
into the hub unchanged through `# <<TYPE_PREAMBLE>>`; its sentences are not
listed.
